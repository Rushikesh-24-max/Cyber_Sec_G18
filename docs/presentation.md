# Group presentation outline

Allow 2–3 minutes per member.

1. Introduce yourself and the feature you own.
2. Show the feature working with normal input.
3. Explain the vulnerability, its impact, and how the fix addresses the root cause.
4. Show that the protected feature still works with normal input.
5. Briefly describe one additional defense and what it covers.
